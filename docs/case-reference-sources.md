# Case Reference Sources

Reviewed on 2026-10-15. Case questions and declension explanations were checked
against the following educational and linguistic references. The app links the
relevant references inside each case lesson, including its practice rule dialog.

| Reference                                                                                                       | Scope                                                     |
| --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| [ZPE: Wśród rzeczowników](https://zpe.gov.pl/a/wsrod-rzeczownikow/DnlcUoa5M)                                    | Noun case questions and inflection.                       |
| [ZPE: Nie przypadkiem jestem przypadkiem](https://zpe.gov.pl/a/nie-przypadkiem-jestem-przypadkiem/DJRrfGJ3Q)    | Contextual case questions and vocative as direct address. |
| [ZPE: Odmiana rzeczownika i przymiotnika](https://zpe.gov.pl/a/odmiana-rzeczownika-i-przymiotnika/DYAl4NsEf)    | Noun/adjective agreement and adjective forms.             |
| [polski.info: Rzeczowniki](https://polski.info/grammar/nouns?hl=pl)                                             | Case use, selected governing verbs and prepositions.      |
| [polski.info: Przymiotniki](https://polski.info/grammar/adjectives?hl=pl)                                       | Adjective forms and agreement.                            |
| [University of Warsaw: wyszukiwać informacje](https://poradniajezykowa.uw.edu.pl/porady/wyszukiwac-informacje/) | The different case requirements of szukać and wyszukiwać. |
| [WSJP PAN: pomagać](https://wsjp.pl/haslo/podglad/25622/pomagac/2729386/w-nauce)                                | Dative recipient in the verb's syntax section.            |
| [WSJP PAN: miejscownik](https://wsjp.pl/haslo/podglad/11882/miejscownik)                                        | Locative case questions.                                  |
| [University of Łódź: wołacz](https://www.poradnia-jezykowa.uni.lodz.pl/szczegoly/wolacz)                        | Direct address and separating it with commas.             |

New example sentences and their analysis were composed for this app. They are not
quotations or exercise sets copied from the sources. Polish remains the default
teaching language, with equivalent Ukrainian explanations selectable in the app.
The questions describe grammatical roles in context; they are not a replacement
for checking a verb's government or a preposition's meaning.
